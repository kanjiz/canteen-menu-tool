# 献立作成ツール

職業訓練施設の寮食堂向け献立作成ツール - TkEasyGUIを使った直感的なGUIアプリケーション

## 🎯 概要

業者から提供される週間献立データを構造化されたJSONファイルに変換し、Google Apps Script経由でGoogleカレンダーに登録するためのデータ作成ツールです。

### 主な機能

- ✅ **週間献立管理**: 月曜日開始の7日分（最大28食分）
- ✅ **改行データ対応**: 業者提供の改行区切りデータに対応
- ✅ **長期休暇対応**: 寮閉鎖期間の部分営業・完全休止に対応
- ✅ **JSON出力**: Googleカレンダー連携用の標準化データ
- ✅ **日付自動計算**: 今週の月曜日を自動設定
- ✅ **バリデーション**: 月曜日チェック・入力検証

## 📊 データフロー

```
業者献立データ → 手動入力 → JSON出力 → メール添付 → GAS → Googleカレンダー
     ↓              ↓          ↓        ↓        ↓           ↓
  改行区切り      GUI操作    menu.json  手動送信   自動処理   カレンダー表示
```

## 🚀 クイックスタート

### 必要な環境

- Python 3.12以上
- tkinter (通常はPythonに同梱、macOSでは `brew install python-tk`)

### インストール

```bash
# リポジトリのクローン
git clone https://github.com/kanjiz/canteen-menu-tool.git
cd canteen-menu-tool

# 依存関係のインストール
uv sync
```

### 使用方法

```bash
# アプリケーションの起動
uv run main.py

# 開発者向け: テスト実行
uv run pytest
```

### 基本的な操作手順

1. **週の開始日確認**: 自動的に今週の月曜日が設定されます
2. **献立データ入力**: 業者提供の改行区切りデータを各食事欄にコピー&ペースト
3. **空欄対応**: 長期休暇で食事がない場合は該当欄を空のまま残してください
4. **JSON作成**: 「JSON作成」ボタンをクリック
5. **ファイル確認**: `menu_YYYY-MM-DD.json` ファイルが作成されます
6. **メール送信**: 作成されたJSONファイルを所定のメールアドレスに添付して送信

### 入力データ例

業者から提供される献立データ（改行区切り）：

```
パン
スープ
ウィンナー
マヨネーズ炒め
飲み物
```

### 出力例

```json
{
  "week_start": "2025-09-08",
  "facility": "職業訓練施設寮",
  "meals": [
    {
      "date": "2025-09-08",
      "day_of_week": "月",
      "breakfast": {
        "menu": "パン\nスープ\nウィンナー\nマヨネーズ炒め\n飲み物",
        "start_time": "07:00",
        "end_time": "08:00",
        "location": "寮食堂"
      }
      // ... 他の食事データ
    }
  ]
}
```

## 🏖️ 長期休暇期間の対応

寮が閉鎖される期間では、以下のように対応してください：

- **部分営業**: 提供される食事のみ入力、提供されない食事は空欄
- **完全休止**: 全ての食事欄を空欄のまま
- **確認ダイアログ**: 全食事が空の場合、長期休暇期間かどうか確認されます

空欄の食事は JSON で `{}` として出力され、Google Apps Script側でカレンダーイベント作成がスキップされます。

## 📋 要件

### システム要件

- **Python**: 3.12以上
- **OS**: Windows, macOS, Linux
- **GUI**: Tkinter (python-tk)

### 業務要件

- **開始日**: 必ず月曜日
- **更新頻度**: 週次（毎週月曜日開始）
- **データ形式**: 改行区切りテキスト（業者提供）
- **出力形式**: JSON（GAS連携用）
