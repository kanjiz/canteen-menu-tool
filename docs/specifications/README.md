## 🔧 システム概要

### プロジェクト範囲

| 責任範囲 | 内容 | 実装状況 |
|----------|------|----------|
| ✅ **本プロジェクト** | 献立データ構造化・JSON出力 | 実装済み |
| ❌ **外部システム** | Googleカレンダー連携（GAS） | 外部実装 |
| ❌ **外部システム** | メール送信 | 手動 |

### 技術スタック

- **GUI Framework**: TkEasyGUI (Tkinterラッパー)
- **言語**: Python 3.9+
- **パッケージ管理**: uv
- **配布**: PyInstaller (EXE化)
- **データ形式**: JSON (UTF-8)

## 📊 データフロー概要

```
業者提供データ → 本ツール → JSON出力 → メール添付 → GAS → Googleカレンダー
 (改行区切り)   (GUI入力)  (構造化)   (手動送信)  (自動)   (イベント登録)
```

### 入力・出力仕様

| 項目 | 仕様 | 詳細 |
|------|------|------|
| **入力** | 改行区切りテキスト | 業者提供の週間献立データ |
| **制約** | 月曜日開始、7日×4食 | 最大28食、空欄許可 |
| **出力** | 構造化JSON | GAS連携用データ形式 |
| **特例** | 長期休暇対応 | 空オブジェクト `{}` 出力 |

詳細なデータ仕様は **[data-specification.md](./data-specification.md)** を参照してください。

## 🏗️ アーキテクチャ概要

### アプリケーション構成

```
main.py (単一ファイル)
├── GUI レイアウト (TkEasyGUI)
│   ├── 開始日入力 (月曜日自動計算)
│   ├── 7日 × 4食の入力フィールド (Multiline)
│   └── JSON出力ボタン
├── バリデーション処理
│   ├── 月曜日チェック
│   ├── 空データ対応
│   └── 長期休暇確認
└── JSON生成・ファイル出力
    ├── データ構造化
    ├── 改行文字処理
    └── UTF-8ファイル出力
```

### 主要機能

| 機能 | 概要 | 実装状況 |
|------|------|----------|
| **自動日付計算** | 今週の月曜日を開始日に自動設定 | ✅ 実装済み |
| **多行入力対応** | 改行を含む献立データの入力 | ✅ 実装済み |
| **空データ処理** | 長期休暇時の空オブジェクト出力 | ✅ 実装済み |
| **月曜日制約** | 開始日の月曜日チェック | ✅ 実装済み |
| **JSON出力** | 構造化データファイル生成 | ✅ 実装済み |

詳細な設計仕様は **[architecture.md](./architecture.md)** を参照してください。

## 🔐 品質・セキュリティ

### 入力検証

| 項目 | 仕様 | 実装 |
|------|------|------|
| **日付形式** | YYYY-MM-DD | 正規表現チェック |
| **月曜日制約** | 開始日が月曜日 | 自動計算・強制検証 |
| **改行処理** | 複数OS対応 | LF統一処理 |
| **空欄許可** | 長期休暇対応 | 空オブジェクト生成 |

### ファイル処理

- **エンコーディング**: UTF-8 固定
- **改行文字**: LF (`\n`) 統一  
- **ファイル名**: `menu_YYYY-MM-DD.json`
- **権限確認**: 書き込み権限の事前チェック

## 🚀 パフォーマンス・制約

### 運用制約

| 項目 | 制約値 | 理由 |
|------|--------|------|
| **開始日** | 月曜日固定 | 週単位管理の業務要件 |
| **期間** | 7日間固定 | 月〜日の1週間分 |
| **食事枠** | 最大28食 | 7日×4食の上限 |
| **メモリ使用量** | < 50MB | 軽量デスクトップアプリ |

### 想定利用パターン

| 項目 | 値 | 備考 |
|------|----|----- |
| **利用頻度** | 週1回 | 業者データ受領時 |
| **データサイズ** | 1-6KB/週 | 内容量による |
| **応答時間** | < 1秒 | GUI操作からファイル出力まで |
| **同時実行** | 単一インスタンス | デスクトップアプリの性質 |
