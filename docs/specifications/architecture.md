# アーキテクチャ仕様書

## 概要

職業訓練施設の寮食堂向け献立作成ツールのアーキテクチャ設計および技術仕様を定義する。

## 背景・目的

### 業務フロー

1. **献立データ受領**: 週次で業者から献立データが届く
2. **データ入力**: 本ツールで構造化されたJSONファイルを作成
3. **データ転送**: 所定のメールアドレスに添付ファイルとして送信
4. **カレンダー登録**: Google Apps Script (GAS) でGoogleカレンダーに自動登録

### プロジェクト責任範囲

- ✅ **献立データの構造化・JSON出力** (本プロジェクト)
- ❌ **Googleカレンダー連携** (GASで実装)
- ❌ **メール送信** (手動)

### 利用シナリオ

- **テスト運用**: 動作検証・ワークフロー確認
- **本格運用**: 日常的な献立データ作成業務での活用
- **長期休暇対応**: 寮閉鎖期間の部分営業・完全休止対応

## システム構成

### アプリケーション層

- **GUI Framework**: TkEasyGUI (Tkinterラッパー)
- **Language**: Python 3.12+
- **Package Manager**: uv

### データ層

- **入力**: 業者から提供される週間献立データ（手動入力）
- **出力**: 構造化されたJSONファイル
- **形式**: Googleカレンダー登録用の標準化データ
- **転送**: メール添付

## コンポーネント設計

### 1. メインアプリケーション (`main.py`)

```
main()
├── 自動月曜日計算
│   └── 今週の月曜日を開始日にセット
├── レイアウト定義
│   ├── 開始日入力（月曜日固定）
│   ├── 7日分（月〜日） × 4食事の入力フィールド
│   │   └── Multiline入力（改行対応、空欄許可）
│   └── JSON作成ボタン
├── イベントループ
│   ├── ボタンクリック処理
│   └── ウィンドウ閉じる処理
└── create_json_file()
    ├── 月曜日バリデーション
    ├── 入力値検証（空欄許可）
    ├── 全食事空チェック（長期休暇確認）
    ├── 日付計算（月〜日）
    ├── JSON構造化（改行保持、空オブジェクト対応）
    └── ファイル出力（menu_YYYY-MM-DD.json）
```

### 2. データ構造

#### 概要

- **特例**: 長期休暇時の空オブジェクト `{}` 対応

## 配布戦略

### 開発者向け（テスト・保守）

```bash
uv sync                # 依存関係インストール
uv run main.py         # アプリケーション実行
```

### エンドユーザー向け（施設職員）

```bash
uv run pyinstaller main.py --onefile --windowed --name canteen-menu-tool
```

→ `dist/canteen-menu-tool.exe` として配布

### 運用フロー

1. **週次作業**: 業者からの献立データをツールに入力
   - 改行区切りデータを各食事のMultilineフィールドにコピー&ペースト
   - 月曜日開始の7日分（最大28食分）を入力
   - 長期休暇期間は該当する食事欄を空欄のまま放置
2. **バリデーション**: 開始日が月曜日であることを自動チェック
3. **休暇確認**: 全食事が空の場合は長期休暇期間か確認
4. **JSON出力**: 構造化されたデータファイルを生成
   - ファイル名: `menu_YYYY-MM-DD.json`（開始月曜日の日付）
   - 空欄の食事は空オブジェクト `{}` として出力
5. **データ転送**: 所定のメールアドレスに添付ファイルとして送信
6. **自動処理**: GASがJSONを読み取りGoogleカレンダーに登録
   - 空オブジェクトの食事はイベント作成をスキップ

## セキュリティ考慮事項

### 入力検証

- **日付形式**: YYYY-MM-DD妥当性チェック
- **月曜日検証**: 入力日が月曜日であることを確認
- **文字列処理**: 改行文字の適切な保持・変換
- **食事入力**: 空欄許可（長期休暇・寮閉鎖対応）
- **営業確認**: 全28食が空の場合は確認ダイアログ表示

### ファイルI/O

- **出力ディレクトリ**: カレントディレクトリ
- **ファイル命名規則**: `menu_YYYY-MM-DD.json`（月曜日の日付）
- **文字エンコーディング**: UTF-8
- **改行文字**: LF（\n）で統一
- **権限確認**: 書き込み権限の事前チェック

## パフォーマンス

### 現在の制約

- **開始日**: 月曜日固定
- **期間**: 7日間固定（月〜日）
- **食事枠**: 最大28食（7日×4食）
- **営業形態**: 通常営業・部分営業・完全休止に対応
- **同時実行**: 単一インスタンス
- **メモリ使用量**: 軽量（< 50MB）
- **ファイル形式**: JSON のみ

### スケーラビリティ

- **対象施設**: 職業訓練施設寮（中規模）
- **利用頻度**: 週1回の献立データ作成
- **データ量**: 週単位（最大7日分×4食）の管理
- **応答時間**: UI操作は即座、JSON出力は1秒以内
- **ファイルサイズ**: 1週間分で約1-2KB（軽量）

## 関連システム

### Google Apps Script (GAS) 連携

- **責任範囲**: JSONデータの読み取り→Googleカレンダー登録
- **入力**: 本ツール出力のJSONファイル
- **処理**: カレンダーイベント作成・更新・削除
- **空データ処理**: 空オブジェクト `{}` の場合はイベント作成をスキップ
- **スケジュール**: 定期実行または手動トリガー

### 想定される運用体制

- **データ入力者**: 施設職員（週1回）
- **システム管理者**: IT担当者（保守・トラブル対応）
- **エンドユーザー**: 寮生（Googleカレンダー閲覧）
