# データ仕様書

職業訓練施設の寮食堂向け献立作成ツールのデータ形式・構造の詳細仕様。

## 📋 概要

本ツールは業者提供の週間献立データを構造化されたJSONファイルに変換し、Google Apps Script経由でGoogleカレンダーに登録するためのデータを作成します。

## 📥 入力データ仕様

### 基本制約

| 項目 | 仕様 | 備考 |
|------|------|------|
| **開始日** | YYYY-MM-DD形式（必ず月曜日） | 自動計算または手動入力 |
| **期間** | 7日間固定（月曜〜日曜） | 週単位管理 |
| **食事数** | 最大28食（7日×4食） | 空欄許可 |
| **食事区分** | 朝食・昼食A・昼食B・夕食 | 昼食は選択制 |

### 献立データ形式

#### 業者提供データ（改行区切り）

```
パン
スープ
ウィンナー
マヨネーズ炒め
飲み物
```

#### GUI入力方式

- **Multiline入力**: 改行を含むテキストエリア
- **コピー&ペースト**: 業者データを直接貼り付け
- **空欄許可**: 長期休暇期間は空のまま放置可能

### 営業形態パターン

#### 1. 通常営業

```
朝食: ○ (メニューあり)
昼食A: ○ (メニューあり) 
昼食B: ○ (メニューあり)
夕食: ○ (メニューあり)
```

#### 2. 部分営業

```
朝食: × (空欄)
昼食A: ○ (弁当のみ提供)
昼食B: × (空欄)  
夕食: × (空欄)
```

#### 3. 完全休止

```
朝食: × (空欄)
昼食A: × (空欄)
昼食B: × (空欄)
夕食: × (空欄)
```

## 📤 出力データ仕様

### ファイル仕様

| 項目 | 仕様 |
|------|------|
| **ファイル名** | `menu_YYYY-MM-DD.json` |
| **文字エンコーディング** | UTF-8 |
| **改行文字** | LF (`\n`) |
| **出力場所** | カレントディレクトリ |

### JSON構造

#### ルートオブジェクト

```json
{
  "week_start": "2025-01-06",      // 週の開始日（月曜日）
  "facility": "職業訓練施設寮",      // 施設名
  "meals": [...]                   // 食事データ配列（7日分）
}
```

#### 食事データオブジェクト

```json
{
  "date": "2025-01-06",           // 日付（YYYY-MM-DD）
  "day_of_week": "月",            // 曜日（月火水木金土日）
  "breakfast": {...},             // 朝食データ
  "lunch": {                      // 昼食データ
    "A": {...},                   // 昼食A
    "B": {...}                    // 昼食B
  },
  "dinner": {...}                 // 夕食データ
}
```

#### 個別食事オブジェクト

##### 通常の食事データ

```json
{
  "menu": "パン\nスープ\nウィンナー\nマヨネーズ炒め\n飲み物",
  "start_time": "07:00",
  "end_time": "08:00", 
  "location": "寮食堂"
}
```

##### 空の食事データ（休止時）

```json
{}
```

## 🕐 時間仕様

### 標準提供時間

| 食事 | 開始時間 | 終了時間 | 備考 |
|------|----------|----------|------|

| **昼食A** | 12:00 | 13:00 | 60分間 |
| **昼食B** | 12:00 | 13:00 | 60分間（Aと同時間帯） |

- 将来的に複数拠点対応時は可変値に変更予定

## 🏖️ 長期休暇対応

### 空データの扱い

#### 入力時

- **空欄**: 該当する食事の入力欄を空のまま放置
- **確認**: 全28食が空の場合、長期休暇期間かどうか確認ダイアログ表示

#### 出力時  

- **空オブジェクト**: `{}` として出力
- **GAS処理**: 空オブジェクトの場合、カレンダーイベント作成をスキップ

### 典型的なパターン

#### 夏季休暇（8月中旬）

```json
// 8月12日〜18日は全て空オブジェクト
{
  "week_start": "2025-08-12",
  "facility": "職業訓練施設寮", 
  "meals": [
    {
      "date": "2025-08-12",
      "day_of_week": "月",
      "breakfast": {}, "lunch": {"A": {}, "B": {}}, "dinner": {}
    },
    // ... 7日分全て空
  ]
}
```

#### 年末年始（部分営業）

```json
// 12月30日は昼食のみ提供
{
  "date": "2025-12-30",
  "day_of_week": "月",
  "breakfast": {},                    // 朝食休止
  "lunch": {
    "A": {
      "menu": "年越し弁当\nお茶",      // 特別メニュー
      "start_time": "12:00",
      "end_time": "13:00",
      "location": "寮食堂"
    },
    "B": {}                          // 昼食B休止
  },
  "dinner": {}                       // 夕食休止
}
```

## 🔍 バリデーション仕様

### 入力検証

#### 必須チェック

- **開始日形式**: `YYYY-MM-DD` 正規表現チェック
- **月曜日制約**: `datetime.weekday() == 0` チェック
- **日付妥当性**: 存在しない日付（2月30日等）のチェック

#### 推奨チェック

- **文字列長**: メニュー文字数の上限チェック（将来実装）
- **文字種**: 使用不可文字のチェック（将来実装）

### 出力検証

#### JSON形式

- **文法チェック**: `json.dumps()` での例外ハンドリング
- **エンコーディング**: UTF-8での保存確認
- **ファイル権限**: 書き込み権限の事前チェック

## 🔄 データ変換フロー

### 処理手順

1. **入力収集**: GUI からMultilineテキストを取得
2. **前処理**: 空白文字のトリム、改行文字の正規化
3. **オブジェクト生成**:
   - 空文字 → `{}`
   - 有効文字 → 完全な食事オブジェクト
4. **JSON構造化**: ルートオブジェクトの組み立て
5. **ファイル出力**: UTF-8エンコーディングで保存

### 改行文字の処理

#### 入力時の改行

- **Windows**: `\r\n` → `\n` に統一
- **macOS**: `\n` → そのまま  
- **Linux**: `\n` → そのまま

#### 出力時の改行

- **JSON内**: `\n` をエスケープして `\\n`
- **GAS読み込み時**: `\\n` を `\n` に復元してカレンダー表示
