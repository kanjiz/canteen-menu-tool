# データ仕様書

## 概要

業者提供の週間献立データを構造化JSONに変換し、Google Apps Script経由でGoogleカレンダーに登録するためのデータ仕様。

## 入力データ

### 基本制約

| 項目 | 仕様 |
|------|------|
| **開始日** | YYYY-MM-DD形式（必ず月曜日） |
| **期間** | 7日間固定（月曜〜日曜） |
| **食事数** | 最大28食（7日×4食） |
| **食事区分** | 朝食・昼食A・昼食B・夕食 |

### 献立データ形式

#### 業者提供データ（改行区切り）

```
パン
スープ
ウィンナー
マヨネーズ炒め
飲み物
```

#### GUI入力方式

- **複数行入力**: 改行を含むテキストエリア
- **手入力**: 紙で提供される業者データを手動入力
- **空欄許可**: 長期休暇期間は空のまま

## 出力データ

### ファイル仕様

- **ファイル名**: `menu_YYYY-MM-DD.json`
- **エンコーディング**: UTF-8
- **出力場所**: カレントディレクトリ

### JSON構造

#### ルートオブジェクト

```json
{
  "week_start": "2025-09-15",
  "facility": "職業訓練施設寮",
  "meals": [...]
}
```

#### 食事データオブジェクト

```json
{
  "date": "2025-09-15",
  "day_of_week": "月",
  "breakfast": {...},
  "lunch": {
    "A": {...},
    "B": {...}
  },
  "dinner": {...}
}
```

#### 個別食事オブジェクト

**通常の食事**:

```json
{
  "menu": "パン\nスープ\nウィンナー\nマヨネーズ炒め\n飲み物",
  "start_time": "07:00",
  "end_time": "08:00", 
  "location": "寮食堂"
}
```

**空の食事（休止時）**:

```json
{}
```

## 時間仕様

| 食事 | 開始時間 | 終了時間 |
|------|----------|----------|
| **朝食** | 07:00 | 08:00 |
| **昼食A** | 12:00 | 13:00 |
| **昼食B** | 12:00 | 13:00 |
| **夕食** | 18:00 | 19:00 |

## 長期休暇対応

### 空データの扱い

- **入力時**: 該当する食事欄を空のまま
- **出力時**: `{}` として出力
- **GAS処理**: 空オブジェクトの場合、カレンダーイベント作成をスキップ

### 確認ダイアログ

全28食が空の場合、長期休暇期間かどうか確認ダイアログ表示

## バリデーション

### 必須チェック

- **開始日形式**: `YYYY-MM-DD` 正規表現チェック
- **月曜日制約**: `datetime.weekday() == 0` チェック
- **日付妥当性**: 存在しない日付のチェック

### JSON出力検証

- **文法チェック**: `json.dumps()` での例外ハンドリング
- **エンコーディング**: UTF-8での保存確認

## 改行文字処理

### 入力時

- **Windows**: `\r\n` → `\n` に統一
- **macOS/Linux**: `\n` → そのまま

### 出力時

- **JSON内**: `\n` をエスケープして `\\n`
- **GAS読み込み時**: `\\n` を `\n` に復元してカレンダー表示

## データサイズ目安

| 要素 | サイズ |
|------|--------|
| **1週間分** | 1-6KB |
| **通常週** | 約3-5KB |
| **休暇週** | 約1KB |
